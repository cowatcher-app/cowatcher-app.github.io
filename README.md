## 🌟 CoWatcher Extension

CoWatcher Extension is your intelligent streaming companion directly inside Netflix, TVer, YouTube, Bilibili, ITVX, Channel 4, and more.

- **AI Dual Subtitles**: Fast translation model paired with reasoning supervisor model for persistent character names and cross-episode consistency.
- **Language Immersion**: In-place click lookup and background vocabulary mining linked to Anki.
- **Automated Tracking**: Zero-friction watch history tracking and viewing heatmap.
